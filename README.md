# Online Retail Sales Analysis
## Project Overview
This project analyzes online retail transactions to understand sales trends, top products and market performance.

## Problem Statement
The objective is to identify business patterns and support better inventory and marketing decisions.

## Dataset Description
The Online Retail dataset was obtained from the UCI Machine Learning Repository. It contains sales transactions with details such as InvoiceNo, Description, Quantity, InvoiceDate, UnitPrice and Country.

## Tools Used
Python, Pandas, Matplotlib, Excel, Power BI, VS Code, Git and GitHub.

## Data Cleaning Process
- Removed duplicate records.
- Removed missing product descriptions.
- Removed zero or negative quantities.
- Removed zero or negative prices.
- Saved the cleaned dataset.

## EDA and Visualizations
EDA was performed using descriptive statistics, correlation analysis, outlier detection and trend analysis.

## Key Insights
1. Total sales are approximately 9.75M.
2. Around 5M units were sold.
3. November showed the strongest monthly performance.
4. The United Kingdom is the strongest market.
5. Quantity and UnitPrice have almost no linear relationship.

## Business Recommendations
1. Maintain sufficient stock of top-selling products.
2. Use targeted promotions to improve sales in other countries.

## Conclusion
The project demonstrates how data analysis and visualization can support better business decisions.
